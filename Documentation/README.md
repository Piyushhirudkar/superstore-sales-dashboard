# Superstore Sales & Profit Dashboard

## Project Overview
This project analyzes Superstore sales data using SQL and Power BI.

## Tools Used
- SQL
- Power BI
- Excel

## Dashboard Features
- KPI Cards
- Sales Analysis
- Profit Analysis
- Customer Insights
- Regional Performance
- Interactive Filters

## Key Insights
- Technology category generated highest sales
- West region achieved highest profit
- Consumer segment contributed maximum revenue
